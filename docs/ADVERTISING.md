# Реклама на сайте

Ротационный баннер в игре, монетизация через ИП владельца. Место — под
галереей «Встроенные паки» (после пагинатора, перед футером, `.ad-slot` в
`index.html`), не под полкой «Популярные озвучки»: изначально сделали там,
но решили, что после самой длинной по контенту секции страницы уместнее.

## VK Ads — текущая сеть

Кабинет — **ads.vk.ru**, регистрация партнёра (не рекламодателя) —
отдельная ссылка **ads.vk.ru/hq/registration/partner**, форма
«Создание кабинета» с выбором «Рекламодатель/Агентство» на главной
ads.vk.ru — это для покупки рекламы, площадкам туда не надо.

Блок — «Дисплейный блок», формат **«Адаптивный»**: ширина растягивается
под контейнер (`width:auto` в сниппете) — но это работает только если в
«Настроить дизайн» отмечена галочка **«Во всю ширину»**, иначе в коде так
и остаётся зажатая исходная ширина (у нас была 950px — шире, чем контент
сайта в 920px). Код при этом может не поменяться сразу после галочки —
подождать и перекопировать заново. Высота — **минимум 250px** по правилам
сети, значение по умолчанию (300–400px) на горизонтальной плашке смотрится
как огромная пустая дыра, особенно пока площадка не одобрена и рекламы нет
вообще.

Настройки блока: «Прямая интеграция» (не Header Bidding — тот нужен для
конкуренции нескольких сетей, у нас одна), «Автоматический» порог CPM (нет
своей статистики, чтобы выставлять порог руками), лимиты показов —
«без ограничений» на старте.

Код (загрузчик в `<head>`, `ins`+`push` в `.ad-slot`) уже живой на проде
независимо от статуса модерации: показывать ли реальный креатив, решает
сервер VK на каждый запрос. Как только площадку одобрят — реклама начнёт
показываться сама, без деплоя. Разгон заполняемости (fill rate) после
одобрения — не мгновенный, первые день-два блок может быть пустым не при
каждой загрузке.

**Реквизиты ИП публиковать на сайте не нужно.** Маркировка рекламы
(отметка «Реклама» + токен `erid`) вшивается в сам креатив скриптом VK
автоматически; идентификация площадки как рекламораспространителя уходит
в ОРД из данных партнёрского кабинета, а не с публичной страницы сайта.
Публичное раскрытие реквизитов по закону обязательно только для
интернет-магазинов (закон о защите прав потребителей) — донаты через
DonationAlerts под это не подпадают.

Поле «сайт компании» в форме вывода средств — просто витринная
информация для модерации/рекламодателей, не юридическое требование
(то закрыто самими паспортными/ИП-реквизитами формы). Указывать нужно
`dubchoice.barinbo.im` — это и есть площадка, на которой крутится
реклама; заводить отдельный «about»-одностраничник под это не нужно.

## Яндекс РСЯ — отклонена, повторно не раньше чем через 30 дней

Заявка отклонена модерацией 2026-08-29 с формулировкой **«Сайт не
соответствует Правилам участия в РСЯ по иным причинам»** — самая
неинформативная из возможных, без конкретики ни в кабинете, ни в письме.
Отказ пришёл меньше чем за 5 минут — по всем признакам автоматика, а не
ручной разбор контента.

Код (`window.yaContextCb`, загрузчик `context.js`, блок
`R-A-19834940-1`) оставлен закомментированным в `<head>` и в `.ad-slot`
на будущее — площадку можно переподать после 2026-09-28.

Вероятные причины (без подтверждения от поддержки Яндекса):
1. **Контент — куски копирайтных фильмов/сериалов без лицензии** (Star
   Wars, Гарри Поттер, Breaking Bad, Shrek, LOTR). Правила РСЯ прямо
   запрещают нелицензированный контент — это структурная особенность
   продукта, не багфикс.
2. **SPA отдавала краулеру почти пустую страницу без выполнения JS** —
   см. «Грабли» в `CLAUDE.md`, фикс уже сделан и задеплоен независимо от
   исхода с Яндексом.
3. Паки с тегом 18+ без возрастного гейта на входе.
4. Домен на момент подачи был младше двух недель по счётчику GoatCounter.

## Прикидка дохода (по трафику на 2026-08-29)

Реальных загрузок главной (не считая событий воронки) — **≈5 700/день**,
растёт; ≈170 000/месяц. Гео за 7 дней: RU ~58%, дальше KZ, US, DE, GB, UA,
NL, BY... Типичный CPM РСЯ/VK для баннера — 30–150 ₽/1000 показов;
геймерская аудитория и заметная доля adblock обычно прижимают к нижней
границе. Грубая оценка на старте — **3 000–12 000 ₽/месяц** с одного
блока, реальная цифра будет видна только по факту показов.

## Юридическая сторона

ИП уже есть — самозанятость не понадобилась. Отдельно с 2025–2026 действует
**сбор 3% с дохода от распространения интернет-рекламы** (372-ФЗ) — платит
и площадка, это не входит в обычный налог по УСН/патенту, нужно не
забыть при подаче отчётности.
