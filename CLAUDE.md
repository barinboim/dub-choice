# Dub Choice — контекст проекта

Браузерная игра-переозвучка: клон режима **Dub Mode** из The Choicer Voicer
(Godot-игра от YeahMaybe), обратно совместимый с фанатскими dub-паками.
Свой дизайн и код, никаких ассетов оригинала. UI на русском и английском.

- Прод: **https://dubchoice.barinbo.im** (GitHub Pages + Actions, репо `barinboim/dub-choice`)
- Владелец: @barinboim (t.me/barinboimgpt)
- Референсы (скриншоты оригинала, файлы разработчика, фанатские паки) лежат
  в родительской папке `../` — она НЕ в git

## Геймплей (не ломать!)

1. Игрок выбирает dub-пак (встроенный из галереи или свой ZIP/папку)
2. Каждая реплика: видео+звук фрагмента → игрок записывает свой дубль,
   бирюзовая волна переписывает пурпурную волну оригинала, курсор бежит.
   Волны двухслойные, как в оригинале: оболочка по пикам + светлая
   сердцевина по RMS (`audio/waveform.ts`)
3. Опционально — отсчёт 3–2–1 перед стартом (галочка над мониторингом; за
   эти секунды прогреваются микрофон и плеер). Начало дубля отсчитывается
   от первого показанного кадра, а не от клика: иначе на медленном
   устройстве запись набирает пустоту и весь дубль уезжает
4. **Пишем шире реплики**: `PRE_ROLL_SEC` 0,5 с до и `TAIL_SEC` 0,75 с после
   (`audio/recorder.ts`). Игрок вступает раньше персонажа и договаривает
   после — раньше это срезалось автостопом. На волне и в оценке — только
   окно реплики (`takeWindow`), в монтаж уходит запись целиком, сдвинутая
   на `leadSec` назад. Реплики в паках и так идут внахлёст (в The Room —
   14 стыков из 17), микс складывает их слоями. **Дозапись хвоста скрыта**:
   на конце волны видео убирается, бейдж гаснет, кнопка на эти 0,75 с
   показывает «Сохраняю…» (`savingTail` в `main.ts`) — игроку не должно
   казаться, что сцена тянется лишнее. «Мой дубль» играет запись целиком,
   с хвостом
5. Дублей сколько угодно, свой дубль можно переслушать сразу («Мой дубль»).
   В оригинале услышать себя до финала было нельзя, и это включалось
   чекбоксом «режим репетиции» — чекбокс убран, репетиция всегда включена
6. **Режим переводчика**: если пак несёт субтитры на нескольких языках,
   над текстом реплики появляются пиллы языков — можно переключиться и
   озвучивать перевод. Стартовый язык — язык интерфейса, если пак его несёт,
   иначе оригинал. Клик по самому тексту открывает поле правки: своя
   версия реплики живёт до конца сессии (`captionEdits` в `session.ts`)
7. **Режим микса** выбирается дважды: на карточке пака (до записи) и на
   экране премьеры. «Дубляж» — только фон + записи, «Закадр» — оригинальный звук
   остаётся под дублем. На премьере два слайдера: «громкость оригинала»
   (только в закадре, `DEFAULT_VOICEOVER_GAIN`; приглушает и голоса, и фон —
   это одна звуковая картина) и «громкость озвучки» (всегда; `TAKE_VOLUME_UNITY`
   = 75 % это «как записано», правее — усиление, лимитер не даст перегрузить). Обе группы
   радиокнопок синхронны (`mixMode` в `main.ts`); смена режима или громкости
   пересобирает дорожку и перезапускает ролик — прежний экспорт выбору уже
   не соответствует. «Мой дубль» на экране записи звучит так же, как будет в
   финале: под голосом фон или приглушённая сцена.
   **Закадр берёт `_original_track`**, если пак его несёт (наши четыре —
   да, чужие — нет): тогда играет целая оригинальная дорожка вместо фона.
   Без неё оригинал собирается из фона и кусков-реплик, и под репликами фон
   выходит примерно на 2 дБ плотнее — с чужими паками иначе никак
8. Финал: ролик с озвучкой игрока. Пока он смотрит, **экспорт MP4 тихо идёт
   под капотом** — «Скачать» отдаёт готовый файл. Отдельно WAV-рендер аудио
9. Там же под роликом — **результаты**, как в оригинале: общий процент,
   шутливый вердикт и строка на каждую реплику (кадр, балл 0–10, волны
   оригинала и дубля рядом). Метрика — `game/score.ts`

## Сборка своих паков

Пайплайн «видео + .srt с ролями → готовый пак» описан в
**`docs/DUBPACK_BUILD.md`**: там сквозная последовательность команд, формат
входного `clips.json`, публикация в галерею сайта и все грабли (demucs,
whisper.cpp, pip). Скрипты — в `scripts/dubpack/`. Так собран встроенный
пак «Гарри Поттер — Я вам не сова!».

## Формат dub-пака (совместимость)

```
_pack_info.ini              # [data] title, subtitle, icon, authors=[...], lang=
dub_video.mp4|.webm|.ogv    # видео сцены; mp4/webm — наше расширение формата
_backing_track.wav|mp3|ogg  # опционально: фон без голосов
_original_track.wav|mp3|ogg # опционально (наше): полная сцена с голосами, для закадра
NN_name.ini|.txt            # [data] caption, caption_<lang>, dub_timestamps=[сек], dub_characters=[...], image=
NN_name.wav|mp3|ogg         # аудио оригинальной реплики
NN_name.png|jpg|webp        # кадр-превью
```

- ini в стиле Godot ConfigFile (`src/pack/ini.ts`); `.txt`-метаданные — так
  делают некоторые моды (Shrek); файлы без `dub_timestamps` — не реплики
- Приоритеты форматов: WAV→MP3→OGG, PNG→JPG→WEBP, MP4→WebM→OGV
- Реплики сортируются по `dub_timestamps[0]`; несколько таймстампов =
  запись вставляется несколько раз
- Паки без dub_video отклоняются с дружелюбной ошибкой (это Voice Packs)
- **Субтитры на втором языке** (наше расширение, подробности в
  `docs/DUBPACK_BUILD.md`): `caption_ru=` рядом с `caption=`, язык
  оригинала — `lang=` в `_pack_info.ini`. Пак считается «переводческим»,
  если перевод есть хоть у одной реплики. Отдельного тега в галерее нет —
  языки перечислены в характеристиках на карточке пака. Русские субтитры
  несут оба пака Star Wars, LOTR, Breaking Bad, Shrek и Harry Potter
- **Картинки реплик необязательны**: без `image` экран показывает само видео,
  поставленное на паузу в `dub_timestamps[0]` (`hideWatchVideo` в `main.ts`).
  Только для mp4/webm — у ogv.js кадр после перемотки на паузе ненадёжен,
  там остаётся плейсхолдер `dub-noimage`
- **Наши паки кадры теперь содержат** (`NN_name.jpg`, высота 480): экрану
  результатов нужны превью всех реплик сразу, перематывать ради этого видео
  дорого. Режет их пайплайн — `scripts/dubpack/make_frames.py`. Для чужих
  паков без картинок миниатюра снимается прямо во время игры: на середине
  просмотра реплики кадр плеера рисуется в маленький canvas (`captureThumb`)

## Архитектура (`src/`)

- `pack/` — `ini.ts` (парсер), `parser.ts` (сборка DubPack), `loader.ts`
  (ZIP через fflate / папка / drag-drop), `preloaded.ts` (галерея встроенных
  паков), `types.ts`
- `audio/` — `recorder.ts` (AudioWorklet → сырой PCM Float32),
  `waveform.ts` (канвас: пики, оверлей записи, курсор), `context.ts`
  (единый AudioContext + wasm-фолбэк OGG для Safari), `wav.ts`
- `video/player.ts` — единый интерфейс DubVideoPlayer: нативный `<video>`
  для mp4/webm, **ogv.js (wasm)** для Theora
- `game/` — `session.ts` (состояние сессии), `composer.ts` (финальный
  монтаж: mute-видео + backing + записи по таймстампам; скрытая запись
  MP4 через canvas.captureStream + MediaRecorder; WAV через OfflineAudioContext),
  `score.ts` (оценка дубля: F1 масок «речь/тишина» + корреляция огибающих,
  с компенсацией общей задержки — балл 0–10 на реплику)
- `i18n.ts` — словарь ru/en, `data-i18n` для статики, `t()` для динамики
- `main.ts` — контроллер экранов (home → pack → dub → final)

## Грабли, на которые уже наступали

- **Theora мертва в браузерах**: Chrome/Firefox/Safari её удалили — .ogv
  играет только через ogv.js. 1080p Theora ogv.js НЕ тянет (слайдшоу),
  поэтому встроенные паки пережаты в H.264 480p mp4. Breaking Bad ехал
  1080p Theora на 812 кбит/с (сыпался на блоки) — пережат в 960×540 H.264
  CRF 23 с `hqdn3d`, без аудиодорожки
- **Аудиотракт ogv.js ненадёжен** (Safari/Arc — тишина): звук реплик ведём
  сами через Web Audio из декодированного буфера, видео всегда muted
- **ogv.js**: свой AudioContext создаёт suspended → передаём наш
  (`{ audioContext }`); вставляет CSS `.ogvjsN{width:...px}` → наш CSS с
  `!important`; canvas кадров — `player._canvas`; ассеты копируются в
  `public/ogv` postinstall-скриптом
- **CDN GitHub (Fastly) бывает мучительно медленным** (10–50 КБ/с из РФ):
  паки качаются с raw.githubusercontent.com (CORS есть), но и он бывает
  медленным. Release-ассеты CORS НЕ отдают — не использовать
- **Лимит файла GitHub — 100 МБ**; больших файлов в репо не держать
- **Микрофон только на HTTPS** — по HTTP getUserMedia отсутствует
  (на этот случай есть отдельное сообщение об ошибке)
- **`[hidden]` перебивается `display:flex`** — в CSS есть
  `[hidden]{display:none!important}`
- Рамкам видео width задаётся явно: контент абсолютный, auto-маржины
  отключают grid-stretch → схлопывание

## Рабочие процессы

- Дев: `npm run dev`; прод-сборка: `npm run build` (tsc + vite)
- Тест парсера на реальных паках: `npm run test:packs -- "путь"`
- Смоук-тесты: Playwright-скрипты в scratchpad сессии (fake-микрофон:
  `--use-fake-device-for-media-stream`, mic-permission через grantPermissions)
- Деплой: push в main → Actions → Pages; кастомный домен уже настроен
- Пережатие видео пака: старые встроенные — H.264 854×480 crf26 + aac 96k
  с jpg-кадрами; новые собираются пайплайном из `docs/DUBPACK_BUILD.md`
  (540p crf28, **без аудиодорожки**, без кадров). У homebrew-ffmpeg НЕТ
  libtheora и libvorbis
