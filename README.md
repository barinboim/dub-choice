# Dub Choice 🎙️

**[dubchoice.barinbo.im](https://dubchoice.barinbo.im)**

Браузерная игра-переозвучка: клон режима **Dub Mode** из The Choicer Voicer,
обратно совместимый с фанатскими dub-паками. Собственный интерфейс и код —
никаких ассетов или дизайна оригинальной игры.

Вдохновлено [The Choicer Voicer](https://yeahmaybe.itch.io/the-choicer-voicer)
от YeahMaybe · Создал [@barinboim](https://t.me/barinboimgpt)

- Интерфейс: русский/английский (автоопределение по системному языку)
- Галерея встроенных паков: поиск, теги, сортировка, страницы по 20
- Свой пак — ZIP с GameBanana, папка или собственное видео
- **Веб-студия**: пак собирается из своего видео прямо в браузере
- Мобильная версия
- Деплой: GitHub Actions → GitHub Pages (см. `.github/workflows/deploy.yml`)

## Как играть

1. `npm install && npm run dev` → открыть http://localhost:5173
2. Выбрать пак в галерее, перетащить свой ZIP/папку — или принести видео
   и собрать пак в студии
3. На карточке пака — фильтр персонажей (выключенных озвучивать не
   придётся, в финале за них звучит их родной голос) и выбор режима микса.
   Нажать «Озвучить!», разрешить доступ к микрофону
4. Каждая реплика сразу играет как видео+звук, курсор бежит по волне.
   Жмёшь «Записать» → озвучиваешь: твоя волна (бирюзовая) переписывает
   оригинальную (пурпурную). Пишется чуть шире реплики — полсекунды до и
   три четверти после, — чтобы можно было вступить раньше и договорить.
   Дублей сколько угодно, свой дубль слышно сразу («Мой дубль»)
5. В финале — премьера ролика с твоей озвучкой. Пока ты смотришь, экспорт
   MP4 уже тихо идёт под капотом: «Скачать» отдаёт готовый файл. Отдельно
   можно забрать аудио в WAV (рендерится офлайн через `OfflineAudioContext`
   — без ожидания) и посмотреть результаты: балл за каждую реплику, волны
   оригинала и дубля рядом

Два режима микса — «Дубляж» (только твой голос поверх фона) и «Закадр»
(оригинальная дорожка остаётся звучать под дублем). Если пак несёт субтитры
на нескольких языках, реплику можно озвучивать в переводе; если несёт
вторую звуковую дорожку — слушать дубляж вместо оригинала.

## Веб-студия (`/studio.html`)

Отдельный документ со своим бандлом: игрок приносит видео (файл, drag-drop
или ссылку на сторонний загрузчик), студия сама режет его на реплики по
звуку и отдаёт готовый пак, который тут же открывается в игре.

- **«Закадр»** — только VAD, работает и на телефоне
- **«Дубляж»** — разделение голос/фон моделью spleeter в ONNX, нужен
  сильный компьютер; веса (78 МБ) едут из R2 и кэшируются
- Редактор — таймлайн с дорожками персонажей; текст реплик пишется руками
- Готовый пак можно скачать, опубликовать в галерею на модерацию или
  вернуть в редактор

Подробности и история решений — `docs/STUDIO_WEB_PLAN.md`.

## Поддерживаемый формат паков

Читаются паки The Choicer Voicer (v0.5+) и наше расширение формата:

```
MyPack/
  _pack_info.ini        # [data] title, subtitle, icon, authors=[...], lang, built, source
  dub_video.mp4         # видео сцены (mp4/webm — наше расширение; ogv — оригинал)
  _backing_track.wav    # опционально: фон без голосов (wav/mp3/ogg)
  _original_track.wav   # опционально (наше): полная сцена с голосами, для закадра
  01_hero.ini           # [data] caption, caption_<lang>, dub_timestamps=[сек], dub_characters=[...]
  01_hero.wav           # аудио оригинальной реплики (wav/mp3/ogg)
  01_hero.jpg           # кадр-превью (png/jpg/webp), необязателен
  ...
```

- Приоритет форматов как в оригинале: аудио WAV → MP3 → OGG, картинки
  PNG → JPG → WEBP, видео MP4 → WebM → OGV
- Реплики сортируются по `dub_timestamps`; несколько таймстампов = запись
  вставляется в видео несколько раз
- Без картинки реплики экран показывает само видео, поставленное на паузу
- Паки без `dub_video` (обычные Voice Packs) вежливо отклоняются

Свои паки собираются пайплайном из `docs/DUBPACK_BUILD.md` (Python +
ffmpeg + demucs) или в веб-студии. Пак для **самой** The Choicer Voicer
(Theora `.ogv` + Vorbis `.ogg`) отдаёт студия: «Скачать» → «The Choicer
Voicer и Dub Choice».

## Технические детали

- Vite + TypeScript, без фреймворка; два документа — игра и студия
- Запись: `getUserMedia` + AudioWorklet (сырой PCM — точный монтаж и живой
  waveform)
- Паки и манифест галереи — Cloudflare R2, не git и не бандл: список паков
  качается при заходе, поэтому новый пак не требует пересборки сайта
- `.ogv` (Theora): современные Chrome/Firefox/Safari уже не играют Theora
  нативно — используется wasm-декодер **ogv.js** (ассеты копируются в
  `public/ogv` на `postinstall`)
- OGG Vorbis аудио в Safari декодируется fallback'ом
  `@wasm-audio-decoders/ogg-vorbis`
- Финальный ролик: видео без звука + фон/оригинал + записи, спланированные
  через Web Audio по `dub_timestamps`, с мастер-лимитером
- Экспорт видео: `canvas.captureStream` + `MediaRecorder` → MP4 (WebM там,
  где браузер не умеет mp4); запись идёт скрыто во время обычного просмотра
  финала, так что «Скачать» отдаёт готовый файл
- Экспорт аудио: `OfflineAudioContext` → WAV (PCM 16 бит) — мгновенный рендер
- Экспорт пака в кодеки Godot 3: **ffmpeg.wasm** в браузере (ядро 32 МБ из
  R2, кэшируется), `src/pack/tcv.ts`
- Оценка дубля: F1 масок «речь/тишина» + корреляция огибающих с
  компенсацией общей задержки, `src/game/score.ts`

## Проверка парсера на реальных паках

```
npm run test:packs -- "путь/к/папке с паками"
```

Печатает по каждому паку число реплик, наличие backing/original/иконки и
языки переводов.
