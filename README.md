# Dub Choice 🎙️

**[dubchoice.barinbo.im](https://dubchoice.barinbo.im)**

Браузерная игра-переозвучка: клон режима **Dub Mode** из The Choicer Voicer,
обратно совместимый с фанатскими dub-паками. Собственный интерфейс и код —
никаких ассетов или дизайна оригинальной игры.

Вдохновлено [The Choicer Voicer](https://yeahmaybe.itch.io/the-choicer-voicer)
от YeahMaybe · Создал [@barinboim](https://t.me/barinboimgpt)

- Интерфейс: русский/английский (автоопределение по системному языку)
- Встроенные dub-паки с загрузкой по клику (крупные — через GitHub Release)
- Мобильная версия
- Деплой: GitHub Actions → GitHub Pages (см. `.github/workflows/deploy.yml`)

## Как играть

1. `npm install && npm run dev` → открыть http://localhost:5173
2. Перетащить в окно dub-пак — ZIP-архив или папку с файлами
3. Нажать «Начать дубляж!», разрешить доступ к микрофону
4. Каждая реплика сразу играет как видео+звук, курсор бежит по волне.
   Жмёшь «Записать» → озвучиваешь: твоя волна (бирюзовая) переписывает
   оригинальную (коралловую), курсор показывает позицию записи.
   Опция «🎧 Оригинал в ухо при записи (50%)» — подсказка темпа (в наушниках).
   Дублей — сколько угодно; «Готово» переводит к следующей реплике
5. В финале — премьера ролика с твоей озвучкой. Пока ты смотришь, экспорт
   WebM уже тихо идёт под капотом: досмотрел до конца — файл скачивается
   мгновенно. Отдельно можно скачать аудиодорожку дубляжа в WAV
   (рендерится офлайн через OfflineAudioContext — без ожидания)

По умолчанию, как в оригинале, свои записи нельзя прослушать до финала.
На карточке пака есть «Режим репетиции», который это разрешает.

## Поддерживаемый формат паков

Полная совместимость с dub-паками The Choicer Voicer (v0.5+):

```
MyPack/
  _pack_info.ini        # [data] title, subtitle, icon, authors=[...]
  dub_video.ogv         # видео сцены (Ogg Theora)
  _backing_track.ogg    # опционально: фон без голосов (wav/mp3/ogg)
  01_hero.ini           # [data] caption, dub_timestamps=[сек], dub_characters=[...]
  01_hero.ogg           # аудио оригинальной реплики (wav/mp3/ogg)
  01_hero.png           # кадр-превью (png/jpg/webp)
  ...
```

- Приоритет форматов как в оригинале: аудио WAV → MP3 → OGG, картинки PNG → JPG → WEBP
- Изображение клипа: файл с тем же именем → `_pack_filler_image` → заглушка
- Реплики сортируются по `dub_timestamps`; несколько таймстампов = запись
  вставляется в видео несколько раз
- Паки без `dub_video.ogv` (обычные Voice Packs) вежливо отклоняются

## Технические детали

- Vite + TypeScript, без фреймворка
- Запись: `getUserMedia` + AudioWorklet (сырой PCM — точный монтаж и живой waveform)
- Автостоп записи по длине оригинальной реплики
- `.ogv` (Theora): современные Chrome/Firefox/Safari уже не играют Theora
  нативно — используется wasm-декодер **ogv.js** (ассеты копируются в
  `public/ogv` на `postinstall`)
- OGG Vorbis аудио в Safari декодируется fallback'ом `@wasm-audio-decoders/ogg-vorbis`
- Финальный ролик: видео без звука + backing track + записи, спланированные
  через Web Audio по `dub_timestamps`
- Экспорт видео: `canvas.captureStream` + `MediaRecorder` → WebM; запись идёт
  скрыто во время обычного просмотра финала, так что «Скачать» отдаёт готовый файл
- Экспорт аудио: `OfflineAudioContext` → WAV (PCM 16 бит) — мгновенный рендер
